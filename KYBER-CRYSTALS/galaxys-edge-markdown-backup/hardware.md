|  | Most of these screws are self-tapping screws, sometimes referred to as "sheet metal" screws. These have a coarser thread pitch than machine screws. |  |  |  |
|  | The self-tapping screws we can find will have a sharp tip, but the ones used in manufacturing will have a blunt tip. You can leave the sharp tip and it may dig into the plastic a little further, or you can trim it off. |  |  |  |
