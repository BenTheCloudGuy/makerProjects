# About

**Last Updated:** 2024.06.02 (Updated Wayfinder quotes to include Series 2 crystals)

## About This Documentation

This collection contains comprehensive documentation about various technologies found throughout **Star Wars: Galaxy's Edge**. Browse the different sections for specific information you're looking for.

## What's Included

- **Holocrons**: Complete list of all audio clips and quotes
- **Kyber Crystals**: Comprehensive list of all known crystals, including colors and voice profiles when inserted into Holocrons
- **Hardware Documentation**:
  - Major ICs inside the Holocrons
  - Infrared protocol for Holocron communication
  - RFID reader/writer tools and analysis
  - Lightsaber chassis and blade PCBs
  - Lightsaber blade/hilt communications
  - Lightsaber blade operations
- **Bluetooth/Beacons**: Analysis of beacons used by droids and the datapad app
- **Astromech Droids**: 
  - Personality chip analysis
  - Documentation for constructing custom personality chips
- **RFID Analysis**: Guide on analyzing RFID reader/writer signals using Proxmark3
- **Image Galleries**: Visual documentation
