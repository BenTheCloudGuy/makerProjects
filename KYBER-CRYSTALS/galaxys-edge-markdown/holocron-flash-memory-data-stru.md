| Basic Data Structure |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The first two bytes on the memory chip identify the number of audio tracks stored on the memory chip. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The next three bytes identify the location (memory offset) within the memory chip where a lookup table is located. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The lookup table contains a 5-byte record for each audio track on the chip. This record identifies the starting location of the audio track and its bitrate(?). |  |  |  |  |  |  |  |  |  |  |  |  |  |
| Audio track data begins with a 32-byte header. It may then be followed by 2 optional headers, mark and silence headers, the presence of which is indicated by the main header. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The mark and silcence headers begin with a 2 byte value identifying how many records are in the header, followed by those records, each of which is a 2-byte value. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| Encoded audio data begins after the last header. The length of the audio data, including all headers, is indicated within the main header. |  |  |  |  |  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |  |  |  |  |
| Audio Format/Codec |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The microcontroller used in Holocrons and Wayfinders to play audio is manufactured by a company called SONIX. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The audio is encoded in a codec that is proprietary to SONIX. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| There is some information online about one such SONIX codec called "Audio32". This audio codec is likely based on the G.722.1 codec (according to this github repo). |  |  |  |  |  |  |  |  |  |  |  |  |  |
| The header for "Audio32" as described in a couple different github repositories appears to align with the header seen in the audio tracks in Holocrons and Wayfinders. |  |  |  |  |  |  |  |  |  |  |  |  |  |
| However, attempts to decode the audio have so far been unsuccessful. |  |  |  |  |  |  |  |  |  |  |  |  |  |
