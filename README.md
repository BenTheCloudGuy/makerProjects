## KYBER CRYSTALS ##

A comprehensive project for understanding and creating custom kyber crystals compatible with Star Wars: Galaxy's Edge technology. This project includes extensive documentation on RFID protocols, holocron hardware, lightsaber electronics, and droid systems. Create your own crystals using 3D-printed resin shells and programmed RFID tags for use in Jedi/Sith Holocrons, Wayfinders, and Savi's Workshop lightsabers.

**Features:**

- Complete RFID tag databases for Series 1 & 2 crystals
- Hardware documentation for holocrons and lightsabers
- 3D-printable crystal designs
- RFID programming guides (Proxmark3)
- Community research and teardown galleries
